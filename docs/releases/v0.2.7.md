# UClone Slices v0.2.7 候选版

- 将“自动回默认账号”开关与“默认账号”选择分开；账号列表不再混入关闭选项，“已选”改为“当前默认”。首次开启先选择账号，取消保持关闭。
- 修复模块更新尚未生效时，旧后台因读取新版模块属性而被误认为兼容的问题。管理器现在校验程序自身的编译版本，提前拦截操作并提示完成模块更新、重启手机。
- 后台程序在写入运行目录前拒绝与自身编译版本不一致的启动配置。

APK 与 KernelSU 模块需配套更新，安装模块后重启手机才能生效；重新连接后台不能应用模块更新。APK 保持既有固定签名，可覆盖安装。已有账号与默认策略保留。

本候选版需完成默认账号实机矩阵后才可作为正式 Release；构建与协议测试不等同于完整实机验收。
