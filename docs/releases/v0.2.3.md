v0.2.3 主要更新

界面

- 首页更简洁：Runtime 状态缩为标题旁的状态点；搜索、添加、备份恢复和刷新移到标题栏图标；账号按钮默认展开。
- 切换和启动的进度显示在被点击的按钮上，不再弹出全屏等待框；应用详情页点开即显示。
- 菜单、开关、进度条和输入框统一为 MIUIX 风格；“重启后自动切换并打开 App”改为菜单中的勾选项。
- 修复深色模式下标题、对话框等文字显示为黑色的问题。

备份与恢复

- 文件数超过约 1.6 万的账号不再提示“备份无效”。
- 备份时每个文件少读一遍，大账号备份更快；备份页和通知显示百分比进度。
- 打开加密备份时直接进入密码页，不再先复制整个文件。

稳定性

- 运行环境页可以重启 Runtime、查看最近日志；Runtime 日志每次启动轮换，不再无限增长。
- 单个 App 的配置文件损坏时，不再影响其他 App 和开机恢复。
- 复制系统原始空间前先检查存储空间，不足时直接提示。
- 切换账号时少调用 3 个系统命令。
- 不包含桌面 Hook。

安装方法

1. 覆盖安装 Manager APK。
2. 在 KernelSU 中刷入同批次模块 ZIP，模块版本应为 0.2.3。
3. 重启设备，确认 Manager 标题旁状态点为绿色。运行环境页的 Runtime 版本仍显示 0.2.2（通信协议未变），属正常。

Manager 与模块必须使用本 Release 的同一批次产物。SHA256SUMS.txt 可用于校验下载文件。
