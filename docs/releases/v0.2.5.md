v0.2.5 主要更新

取消配置

- 取消配置后，分空间不再立即删除，而是移入回收区保留 7 天；7 天后由 Runtime 在开机或下一次取消配置时永久删除。确认面板和完成提示的文字同步更新。
- 移入回收区分两步完成，CE 与 DE 都移入后才开始计时；中途中断时，下次打开或重启会从中断处继续，不会提前删除。

界面

- Manager 改为 iOS 27 Liquid Glass 风格，移除 MIUIX；Android 12 及以上实时绘制玻璃效果，更低版本退化为不透明表面。
- 顶部提示可以可靠地显示和关闭，可上滑或点击收起。
- 备份与恢复页面禁止截屏和出现在最近任务缩略图中；备份或检查结束后释放所选备份文件的访问授权；备份失败时不再删除原本已有内容的文件。

可靠性与安全

- Runtime 以 Root 身份处理 App 数据（重标 SELinux 标签、校验暂存恢复、备份扫描）时不再跟随 App 目录中的符号链接；解包恢复前检查剩余空间。
- 账号 I/O 恢复失败时保留记录并可重试，不再吞掉错误；深层目录不再耗尽线程栈，强制停止时的 `/proc` 扫描开销降低。
- Manager 可识别较新 Runtime 返回的未知错误码和状态，不再误判 Runtime 不可用；修复应用列表和 Runtime 日志的异步竞态。

其他

- 通信协议命令、字段和错误码不变，但 Runtime 协议 ID 升为 0.2.3：旧 Runtime 会立即删除分空间，与新 Manager 的说明不符，因此 Manager 与模块必须同时更新。
- 内部代码整理：拆分大文件、统一校验与路径常量、删除无用代码，CI 精简。
- 不包含桌面 Hook。

安装方法

1. 覆盖安装 Manager APK。
2. 在 KernelSU 中刷入同批次模块 ZIP，模块版本应为 0.2.5。
3. 重启设备，确认 Manager 标题旁状态点为绿色。运行环境页的 Runtime 版本显示 0.2.3（协议 ID）。

Manager 与模块必须使用本 Release 的同一批次产物。SHA256SUMS.txt 可用于校验下载文件。
