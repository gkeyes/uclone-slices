v0.2.4 主要更新

界面

- Manager 界面按统一设计规范重做：间距、圆角、字号、文字层级、浅色/深色表面和状态颜色统一；Android 12 及以上跟随系统动态取色。
- 所有页面使用可随滚动收起的大标题；分组标题位于卡片外，卡片内不再使用分隔线。
- 卡片、按钮、列表行有按压缩放反馈；开关、分段选择、确认和危险操作带触感反馈。
- 页面切换、弹窗进出、展开收起、状态文字和数字变化使用弹簧动效；系统关闭动画时直接显示最终状态。
- 配置应用、重命名、删除空间、取消配置、重新绑定、创建空间统一为可下拉关闭的底部面板，支持预测性返回。
- 空列表、加载中和错误状态统一为带图标的提示；备份恢复各步骤、进度和结果页同步更新。

首页排序

- 首页标题栏新增“排序”：拖动右侧把手或长按应用调整顺序，越过一个位置有轻触感，松手确认；也可在每行菜单或 TalkBack 中“上移/下移”。
- 点“完成”保存，“取消”或返回放弃。顺序只保存在本机 Manager，新配置的应用排在最后；搜索时不显示排序入口。

其他

- 功能、Runtime 行为和通信协议不变；Runtime 协议 ID 仍为 0.2.2。
- 不包含桌面 Hook。

安装方法

1. 覆盖安装 Manager APK。
2. 在 KernelSU 中刷入同批次模块 ZIP，模块版本应为 0.2.4。
3. 重启设备，确认 Manager 标题旁状态点为绿色。运行环境页的 Runtime 版本仍显示 0.2.2（通信协议未变），属正常。

Manager 与模块必须使用本 Release 的同一批次产物。SHA256SUMS.txt 可用于校验下载文件。
