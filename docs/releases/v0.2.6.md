# UClone Slices v0.2.6 候选版

- 每个 App 可设置默认账号，选择系统原始空间或任意已有账号，也可关闭。
- 从外部打开或真正离开后回到前台时自动回默认；从 Slice 选择的账号在当前会话内有效。
- App 内页面切换以及由当前任务发起的拍照、文件选择、支付和锁屏返回保留当前账号。
- 删除默认账号前明确提示，并在删除成功时关闭该 App 的自动回默认。
- 返回 Slice 时被动刷新自动切换后的账号状态，避免首页继续高亮旧账号。

Manager 与 KernelSU 模块必须成对升级。APK 继续使用固定 Release 签名，可覆盖安装；旧账号配置升级后默认关闭本功能。

候选包需要完成默认账号真机矩阵后才可发布为正式 Release。自动切换会重新打开到默认账号首页，不保证保留旧账号通知的页面和回调。
