# Zygisk API reference

`zygisk.hpp` is copied without modification from the official Zygisk module sample at API 4 commit `7bb941ac8edfcffd1d23761e401c45ca95409dc1`. Its original copyright and ISC license are preserved in the header. API 4 supplies all capabilities used here and is deliberately retained for Zygisk Next compatibility; no API 5 capability is needed.
